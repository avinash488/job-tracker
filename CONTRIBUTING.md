# Contributing to Job Tracker

Thanks for your interest in contributing! Here's how to get started.

---

## 🛠️ Local Setup

Follow the Getting Started steps in the [README](./README.md) to run the project locally.

---

## 🌿 Branch Naming

| Type | Format | Example |
|------|--------|---------|
| Feature | `feature/description` | `feature/csv-export` |
| Bug fix | `fix/description` | `fix/modal-close-bug` |
| UI | `ui/description` | `ui/kanban-redesign` |

---

## 📦 Commit Messages

Use clear, lowercase commit messages:

```
add csv export feature
fix follow-up date null error
update kanban card styles
```

---

## 🔁 Pull Request Process

1. Fork the repository
2. Create a new branch from `main`
3. Make your changes
4. Test locally
5. Open a Pull Request with a clear description of what you changed and why

---

## 🐛 Reporting Bugs

Open a GitHub Issue with:
- What you expected to happen
- What actually happened
- Steps to reproduce
- Screenshots if applicable

---

## 💡 Suggesting Features

Open a GitHub Issue with the `enhancement` label and describe:
- The problem it solves
- How you'd expect it to work
